# RoboPilot Lab：一起做的路线

目标：用 **视觉感知 + Agent 任务规划 + 机器人闭环控制** 做一个能复现实验、能解释失败原因的作品。预计 6 周，每周 15–20 小时。它能同时支撑多模态/视觉算法、AI Agent 工程，以及机器人决策方向的申请。

## 路线

| 周 | 核心问题 | 可检查的成果 |
| --- | --- | --- |
| 1 | 机器人能否只凭局部图像找到可见目标？ | 完成颜色目标检测与 PID/比例控制基线；记录成功和失败回放 |
| 2 | 未见过的地图与噪声会怎样？ | 固定数据划分，批量评测、失败分类、可视化 |
| 3 | 学习型视觉策略能否超过手工规则？ | 用专家轨迹训练小型 CNN/ViT 视觉策略，做消融实验 |
| 4 | 语言任务如何转成连续行动？ | Agent 将目标序列转换为受限工具动作；有步数、超时和无效动作处理 |
| 5 | 动态障碍与安全约束如何处理？ | 加安全层和障碍扰动，评测碰撞率与恢复率 |
| 6 | 如何说服面试官结果可信？ | 冻结测试集、整理误差分析、录制演示、写简历项目条目 |

控制变量：只在相同测试地图、相同传感器噪声和相同时间预算下比较方法。LLM/VLM 可以作为高层规划器的可选实现，不作为项目成功的前提。8 GB GPU 足够先训练小型视觉网络；不以本地训练大型 VLM 为目标。

## 第一课：做出不作弊的视觉基线

仓库已经有可运行的模拟器。先读 `src/robopilot/env.py` 中的 `Observation`、`reset`、`step`，再运行 demo 看两张图。

请你新建 `src/robopilot/baselines/color_tracker.py`，实现一个函数：

```python
def choose_action(observation: Observation, target: str) -> Action:
    ...
```

要求：

1. 只读 `observation.image`，不得读取 `env.pose`、`env.stations` 或地图真值。
2. 从图像中找到指定颜色的像素中心；目标不在画面里时原地搜索。
3. 根据目标相对图像中心的方向给出线速度和角速度；靠近目标时减速。
4. 写至少两个测试：目标在视野左/右侧时转向相反；无目标时不盲目前进。
5. 保存一段成功回放和一段失败回放，说明失败原因。

完成后把代码或 Git commit 发我，我会 review 视觉检测、坐标系和控制稳定性，再一起把它扩展到批量评测。暂时不要跳到大模型调用：先有可信基线，后续模型的提升才有意义。

## 简历结果的底线

只有在测试集冻结后，才写成功率等数字。明确区分模拟器与真机、训练地图与未见地图、自动化评测与手选演示。不要把计划中的模型或未来目标写成已完成成果。
